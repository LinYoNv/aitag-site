# AI绘画咒语图库站 · 建设大纲

> 参照 `/root/dsh-work/aitag/` 的结构复刻蓝图，自建一个**自有数据**的 AI 绘画作品 / 咒语（Prompt）检索图库站。
> 目标：先在本地搭好、调通，你验收后再搬到自己的服务器/域名使用。
> 版本：v0.1（待你拍板的点见文末「待确认」）。

---

## 一、站点定位

- **是什么**：一个面向 Stable Diffusion / ComfyUI / NovelAI 用户的「AI 绘画作品 + Prompt 咒语」检索库。
- **核心价值**：能搜到作品，并且点进去能看到那张图的**提示词/参数**（SD/NAI 的 metadata），方便学习、参考、改咒语。
- **与原站的关系**：结构、页面、交互「形似」aitag.win，但**数据是你自己的**，不搬原站数据；并砍掉合规/埋点等业务杂质。

---

## 二、页面结构（路由）

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 首页 | 顶部搜索 header + hero 简介 + 画廊栅格 + 分页/无限滚动 + 右下角悬浮设置 |
| `/i/[id]` | 详情页 | 单作品详情：图片组浏览 + 标题/作者/简介/日期/tags + **prompt/参数元数据**；有返回入口 |
| `（可选）` | 月榜页 / 关于页 / 分类页 | 按需再加，首期可先不做 |

> ✅ 你说的「点进去跳到另一个页面」——原站 `/i/149148566` 是 SPA 里的伪路由；我们做成 **Next.js 真实路由**，URL 可复制分享、可被搜索引擎收录，体验更好。

## 三、功能清单

**保留（原站精髓）**
1. **卡片**：1:1 方形封面 + 左上「类型徽章」(SD=橙 / NAI=蓝 / NAI-X=深蓝 / ComfyUI=紫) + 右上「图数角标」 + 左下信息层(标题/作者/简介/日期)。
2. **画廊栅格**：`grid-auto-flow: dense` 瀑布填充，列数随屏宽 `6 → 4 → 2`。
3. **搜索**：作品ID / 作者ID或名 / 简介 / tags / 日期 / AI类型 / 模型；支持 `-排除`、`OR`、`"精确短语"`。
4. **Prompt 检索**：按 SD/NAI 的 metadata prompt 搜（这是本站区别于普通图站的关键）。
5. **排序/时间**：`new`(最新) / `monthly`(月榜)；时间范围 all/…
6. **悬浮预览**：鼠标悬停卡片，跟随显示标题+预览图。
7. **详情页**：图片组切换 + AI 元数据两种视图（JSON 原文 / 格式化「指令」视图）。
8. **多语言**：先做 简体中文 + English 两套（原站有 zh/zh_tw/en/ja/ko，后续可扩）。
9. **月榜卡片角标**：浏览/收藏数 metrics。

**裁剪（原站业务特性，非结构必需）**
- ❌ R-18 / 敏感内容合规层（sensitive_filter + /api/sensitive_*）
- ❌ Cloudflare challenge/beacon 埋点
- ❌ 首次公告弹窗
- ❌ naix 自动检测、无效 tag 开关等

## 四、技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | Next.js 15（App Router）+ TypeScript | 前后端一体，同源 `/api`，适合自建站点 |
| 样式 | Tailwind CSS + 少量自定义 CSS 变量 | 快速还原深色主题 + 栅格 |
| 数据库 | SQLite（Node 24 内置 `node:sqlite`） | 零额外依赖、单文件、方便「搬到别的服务器」 |
| 接口 | Next.js Route Handlers（同源 `/api/*`） | 与原站同源接口思路一致 |
| 图片 | 本地 `public/images/...` 占位图 + 可换 CDN | 自建存储；结构上留好 CDN 前缀切换点 |
| 部署 | `next build` → Node 运行（pm2 / systemd / Docker 均可） | 你要搬到别的服务器，给出部署说明 |

## 五、数据模型（作品表 `works`）

| 字段 | 含义 |
|---|---|
| `id` | 作品 ID（自建站内唯一） |
| `title` / `caption` | 标题 / 简介 |
| `create_date` | 创建日期 |
| `ai_type` | `sd` / `nai` / `nai_x` / `comfyui` |
| `image_count` | 图片数（角标） |
| `tags` | 标签（JSON 数组，用于检索/黑名单） |
| `author_id` / `author_name` | 作者 |
| `total_view` / `total_bookmarks` | 月榜 metrics |
| `images` | 图片文件名数组 |
| `metadata` | prompt / 负面 prompt / 参数（JSON，详情页展示） |

## 六、API 设计（同源 `/api/*`）

| 方法/路径 | 用途 |
|---|---|
| `GET /api/config` | 站点配置（图片前缀、语言等） |
| `GET /api/works` | 列表/搜索（`q`、`prompt`、`sort`、`time_range`、`page`、`page_size`） |
| `GET /api/works/[id]` | 单作品详情（含 images / metadata） |
| `GET /api/rank/monthly` | 月榜 |

## 七、开发里程碑（建议分 5 步，每步可验收）

1. **脚手架**：Next.js + TS + Tailwind 初始化，深色主题 + 设计变量落地。
2. **数据层**：建 `works` 表 + 种子数据（几十条示例作品）+ 本地占位图。
3. **API**：`config` / `works` 列表搜索 / `works/[id]` 详情 / 月榜。
4. **首页**：画廊栅格 + 卡片 + 搜索排序 + 分页/无限滚动 + 悬浮预览。
5. **详情页** `/i/[id]`：图片组 + 元数据（JSON/指令视图）+ 中英语言切换 + 打包与迁移说明。

---

## 八、部署到你的服务器（形态预案）

- 生产：`next build` 产出后，在目标服务器 `node .next/standalone`（或 pm2/systemd 守护），Nginx 反代域名。
- 搬运清单：代码 + `*.db`（SQLite 数据文件）+ `public/images/`（图片）。
- 可切换项：图片换成自己的对象存储/CDN 时，只需改前缀配置。
